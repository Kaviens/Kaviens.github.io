###

| ██████████████ 状态栏 (Status Bar) | ← 系统区域，显示时间、电量等
+------------------------------------------+

## 自定义导航示例

### 在pages.json中，谁在第一个，谁就是小程序后打开的首页

```vue
{ "pages": [
//pages数组中第一项表示应用启动页，参考：https://uniapp.dcloud.io/collocation/pages
{ "path": "pages/index/index", "style": { "navigationBarTitleText": "首页",
"navigationStyle": "custom" // 使用自定义导航栏 } } ], "globalStyle": {
"navigationBarTextStyle": "black", "navigationBarTitleText": "uni-app",
"navigationBarBackgroundColor": "#F8F8F8", "backgroundColor": "#F8F8F8" } }
```

### 导航栏

```vue
//获取状态栏高度，导航栏不能阻挡状态栏
const systemInfo = uni.getSystemInfoSync();
const statusBarHeight = systemInfo.statusBarHeight;

//获取胶囊按钮高度，胶囊按钮也就是小程序右上角的分享按钮
const menuButton = uni.getMenuButtonBoundingClientRect();
// 顶部间隙 = 胶囊按钮顶部 - 状态栏高度
const gap = menuButton.top - statusBarHeight;
// 导航内容区高度 = 胶囊按钮高度 + 顶部间隙 * 2
const navContentHeight = menuButton.height + gap * 2;

返回的都是px，而不是rpx，所以要用px单位

//样式
    <view class="custom-nav" :style="{ paddingTop: statusBarHeight + 'px' }">
      <view class="nav-content" :style="{ height: navContentHeight + 'px' }">
        <view class="nav-back" @click="goBack">
          <text>←</text>
        </view>
        <text class="nav-title">页面标题</text>
      </view>
    </view>
```

### 内容区计算，不遮挡上也不遮挡下

```vue
//状态栏和导航栏高度 navBarHeight=statusBarHeight + navContentHeight //
底部安全区的高度，单位 px，如果设备没有则返回 0 const bottomSafeHeight =
systemInfos.safeAreaInsets?.bottom || 0;
100vh也就是一屏幕，减去底部安全区，底部按钮的高度+padding,再减去导航栏和状态栏高度，剩下就是内容区的高度，24rpx是根据情况进行调整
<scroll-view
  scroll-y
  class="main-content"
  :style="{
    height: `calc(100vh - 128rpx - 24rpx - ${bottomSafeHeight}px - ${navBarHeight}px )`,
    marginTop: navBarHeight + 'px',
  }"
>
      <!-- 内部布局用 rpx -->
      <view class="card" v-for="item in 20">
        <text class="card-title">标题</text>
        <text class="card-desc">描述内容</text>
      </view>
    </scroll-view>
```

## 插件

首先要安装 HBuilder X，因为uni-app是基于HBuilder X开发的，虽然我们后面使用vsc了，但是装这个是为了小程序的插件，因为小程序的插件下载是要通过这个软件来的，小程序的插件有些可以不用npm i下载依赖，可以直接去插件市场里面进行下载，下载下来也不和那些依赖一样，把下载下来的当成一个封装的的组件就行

https://ext.dcloud.net.cn/

<template>
  <view class="page">
    <!-- 自定义导航栏，高度由 JS 动态计算，用 px -->
    <view class="custom-nav" :style="{ paddingTop: statusBarHeight + 'px' }">
      <view class="nav-content" :style="{ height: navContentHeight + 'px' }">
        <view class="nav-back" @click="goBack">
          <text>←</text>
        </view>
        <text class="nav-title">页面标题</text>
      </view>
    </view>

    <!-- 主内容区 -->
    <scroll-view
      scroll-y
      class="main-content"
      :style="{
        height: `calc(100vh - 128rpx - 24rpx - ${bottomSafeHeight}px - ${navBarHeight}px )`,
        marginTop: navBarHeight + 'px',
      }"
    >
      <!-- 内部布局用 rpx -->
      <view class="card" v-for="item in 20">
        <text class="card-title">标题</text>
        <text class="card-desc">描述内容</text>
      </view>
    </scroll-view>

    <!-- 底部固定按钮 + 安全区适配 -->

</template>

<script setup lang="ts">

// 顶部间隙 = 胶囊按钮顶部 - 状态栏高度
const gap = menuButton.top - statusBarHeight;
// 导航内容区高度 = 胶囊按钮高度 + 顶部间隙 * 2
const navContentHeight = menuButton.height + gap * 2;
const navBarHeight = statusBarHeight + navContentHeight;
const mainHeight = systemInfo.windowHeight - navBarHeight;
const bottomSafeArea = systemInfo.screenHeight - systemInfo.safeArea.bottom;

// 底部安全区的高度，单位 px，如果设备没有则返回 0
const bottomSafeHeight = systemInfos.safeAreaInsets?.bottom || 0;

console.log("底部安全区高度:", bottomSafeHeight);
const goBack = () => {
  uni.navigateBack({ delta: 1 });
};
</script>
