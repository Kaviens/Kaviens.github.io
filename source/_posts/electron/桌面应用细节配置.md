# 桌面应用细节配置（以electron-vite框架为例）

## 创建第二个窗口

### 在主进程窗口底下创建一个差不多的参数的窗口

```
  let settingsWindow: BrowserWindow | null = null
 settingsWindow = new BrowserWindow({
      width: 430,
      height: 280,
      show: false,
      autoHideMenuBar: true,
      fullscreen: false,
      skipTaskbar: true,
      frame: false,
      webPreferences: {
        preload: join(__dirname, '../preload/index.js'),
        sandbox: false
      }
    })
```

### 其次在dev环境和prod环境打开窗口方式是不一样的

```
// 如果是开发环境，则使用electron-vite的代理服务器加载页面
// 其中is.dev是electron-vite内置的判断开发环境的变量，process.env['ELECTRON_RENDERER_URL']是electron-vite内置的环境变量。
//loadURL是加载本地开发环境的页面，loadFile是加载打包后的生产环境页面。

    if (is.dev && process.env['ELECTRON_RENDERER_URL']) {
      settingsWindow.loadURL(process.env['ELECTRON_RENDERER_URL'] + '/settings.html').then(() => {
        settingsWindow?.show()
      })
    } else {
      // 修改生产环境路径
      settingsWindow.loadFile(join(__dirname, '../renderer/settings.html')).then(() => {
        settingsWindow?.show()
      })
    }
```

###打包时配置（要先在electron.vite.config进行配置）

```
// 打包时配置
 renderer: {
    resolve: {
      alias: {
        '@': resolve(__dirname, './src/renderer/src')
      }
    },
    plugins: [vue()],
    build: {
      /** 打包输出目录 */
      rollupOptions: {
        /** 打包入口文件 */
        input: {
          index: resolve(__dirname, 'src/renderer/index.html'),
          settings: resolve(__dirname, 'src/renderer/settings.html')
        }
      }
    },
    server: {
      /** 设置 host: true 才可以使用 Network 的形式，以 IP 访问项目 */
      host: true, // host: "0.0.0.0"
      /** 端口号 */
      port: 3333,
      /** 是否自动打开浏览器 */
      open: false,
      /** 跨域设置允许 */
      cors: true,
      /** 端口被占用时，是否直接退出 */
      strictPort: false,
      /** 接口代理 */
      proxy: {
        '/itc': {
          target: 'http://172.16.19.122:8800/itc',
          ws: true,
          /** 是否允许跨域 */
          changeOrigin: true,
          rewrite: (path) => path.replace('/itc', '')
        }
      }
    }
  }
```

```

app.mount('#settingApp')

```

## 一、Electron 日志系统


###  安装 electron-log

```bash
npm install electron-log
```

就这一个包，主进程和渲染进程都能用，不用配一堆东西。

### 主进程里使用日志

```ts
// src/main/index.ts 顶部引入
import log from "electron-log/main";

// 初始化（一定要在 app.whenReady() 之前调用）
log.initialize();

// 设置日志文件存放路径（可选，默认在用户目录下）
// Windows: C:\Users\用户名\AppData\Roaming\my-app\logs\main.log
// Mac: ~/Library/Logs/my-app/main.log
log.transports.file.resolvePathFn = () => {
  return join(app.getPath("userData"), "logs", "main.log");
};

// 设置日志文件大小上限（超过自动切割，防止日志文件太大）
log.transports.file.maxSize = 5 * 1024 * 1024; // 5MB

// 然后就可以到处用了
log.info("应用启动了");
log.error("出错了：", someError);
log.warn("警告信息");
log.debug("调试信息"); // debug 级别默认不写文件，只输出到控制台
```

###  渲染进程里使用日志

```ts
// 在 Vue 页面里直接用
import log from "electron-log/renderer";

// 用法和主进程一模一样
log.info("用户点击了按钮");
log.error("接口请求失败：", error);

// 在 Vue 组件里的用法
import { onMounted } from "vue";
import log from "electron-log/renderer";

onMounted(() => {
  log.info("主窗口已加载完成");
});
```

###  让渲染进程的日志也写到文件里

默认情况下，渲染进程的 `electron-log` 只输出到 DevTools 控制台。要让它也写到文件，需要在主进程里做一下配置：

```ts
// src/main/index.ts
import log from "electron-log/main";

// 在 app.whenReady() 里调用
app.whenReady().then(async () => {
  // 初始化日志，这一步会让渲染进程的日志也走主进程的文件写入
  log.initialize({ preload: true });

  // ... 其他初始化代码
});
```

> **大白话解释：** `preload: true` 的意思是"在 preload 脚本里注入日志功能"，这样渲染进程调用 `log.info()` 的时候，实际上是发消息给主进程，由主进程统一写文件。

###  日志文件在哪？怎么让用户发给你？

```ts
// 在主进程里获取日志文件路径
import log from "electron-log/main";

const logPath = log.transports.file.getFile().path;
console.log("日志文件路径：", logPath);
// Windows 输出类似：C:\Users\lij\AppData\Roaming\my-app\logs\main.log
```

你也可以加一个 IPC 接口，让设置页面有个"打开日志目录"按钮：

```ts
// 主进程
import { shell } from "electron";
import log from "electron-log/main";

ipcMain.on("open-log-folder", () => {
  const logPath = log.transports.file.getFile().path;
  // 在文件管理器里打开并选中这个文件
  shell.showItemInFolder(logPath);
});

// 渲染进程（Vue 页面里）
window.api.send("open-log-folder");


```

### 日志格式自定义

```ts
// 设置日志输出格式
log.transports.file.format = "[{y}-{m}-{d} {h}:{i}:{s}.{ms}] [{level}] {text}";

// 输出效果：
// [2026-07-31 16:00:00.123] [info] 应用启动了
// [2026-07-31 16:00:01.456] [error] 出错了：xxx
```

###  完整的主进程日志配置（直接抄）

```ts
// src/main/index.ts
import { app } from "electron";
import log from "electron-log/main";
import { join } from "path";

// ====== 日志配置（放在文件最顶部，app.whenReady 之前） ======

// 1. 初始化日志系统
log.initialize({ preload: true });

// 2. 设置日志文件路径
log.transports.file.resolvePathFn = () => {
  return join(app.getPath("userData"), "logs", "main.log");
};

// 3. 设置日志文件大小上限
log.transports.file.maxSize = 5 * 1024 * 1024; // 5MB

// 4. 设置日志格式
log.transports.file.format = "[{y}-{m}-{d} {h}:{i}:{s}.{ms}] [{level}] {text}";

// 5. 设置控制台输出格式（开发时用）
log.transports.console.format = "[{h}:{i}:{s}.{ms}] [{level}] {text}";

// 6. 设置日志级别（生产环境只记 info 及以上，开发环境记所有）
log.transports.file.level = "info";
log.transports.console.level =
  process.env.NODE_ENV === "development" ? "debug" : "info";

// ====== 日志配置结束 ======

log.info("========== 应用启动 ==========");
log.info("版本号：", app.getVersion());
log.info("系统：", process.platform, process.arch);

app.whenReady().then(() => {
  log.info("应用 ready，开始创建窗口...");
  createWindow();
});
```
