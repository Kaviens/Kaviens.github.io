# 自定义发送二进制文件

其实在工作中，可能有厂商进行一个对接，例如要将什么数据发送到socket，什么标头，什么数据体，这时候就需要自定义发送二进制文件。

## 字节讲解
```vue
Uint=无符号整数类型，Uint8、Uint16等。
8 / 16 = 占用比特 bit数量
8 bit = 1 字节 Byte
Uint8 每个数据占用空间是1个字节，也就是8位Byte。
Unint16 每个数据占用空间是2个字节，也就是16位Byte。
Uint8[64]就是64个Uint8元素组成的数组，总共占用64个字节。
ASCII 码就是数字对应字符串的一个表，让计算机用数字来表示英文字母、数字和符号。
```

## 类使用讲解
```vue
new ArrayBuffer() 地皮
单纯一块原始内存，开辟一个内存空间，例如要开辟100字节的空间，就new ArrayBuffer(100)，相当于是一个容器

`new DataView(buffer)`、`new Uint8Array(buffer)`
这两个是用来操作开辟的内存空间的，相当于是往里面进行一个填充

new Uint8Array  地皮 + 施工工具 const bytes = new Uint8Array(buffer)

取值范围：`0 ~ 255`
但是如果取值范围`>255`，则会溢出，例如：new Uint8Array([256])，则会变成0。new Uint8Array([255])这是可以的。就变成255。参数里面是数组，那么长度是1
new Uint8Array (数字) → 分配空空间
FRAME_HEADER=new Uint8Array([0x63,0x6F,0x64,0x65])
FRAME_HEADER里面是四个字节，分别是：c o d e，看起来是16进制，但是实际上在内存中是以二进制的形式存储的。同时，里面的四个数字按照ASCII码表，转换成二进制形式存储的。
使用变量进行接收new Uint8Array，这个变量的set方法有两个参数
bytes.set(FRAME_HEADER, offset) 
第一个参数不能是单纯数字或者字符串，可以是数组但是里面元素必须是0~255，也可以是new Uint8Array([0x63,0x6F,0x64,0x65])，里面也必须是变成二进制也是在 0-255 内
其次多说一下，假设是连续的字符串，例如帧头标识，就用这个，因为每个都是占用独立的一个空间，并且是连续用四个的，假设用new DataView(buffer).setUint8(offset, 0x63) ,虽然也是独立的一个空间，这样就要循环四次，而用new Uint8Array([0x63,0x6F,0x64,0x65])，就只需要一次。相当于是批量填充。不然
用DataView就是
view.setUint8(offset, 0x63);
view.setUint8(offset+1, 0x6F);
view.setUint8(offset+2, 0x64);
view.setUint8(offset+3, 0x65);
const bytes = new Uint8Array(value)如果value本身有ArrayBuffer且里面有数据，就直接用这个ArrayBuffer开辟的空间填充就不会是0000。如果value是数字或者字符串，则会重新分配空间，结果也是0。



new DataView()  地皮 + 施工工具 const view = new DataView(buffer)
DataView他本身有个好处，就是可以选择用两个字节的空间存储一个值，而Uint8Array只能一个字节，同时可以控制大小端，小端的意思是低位在前，高位在后。大端的意思就是高位在前，低位在后。
setUint8(offset, value,true) 填充一个字节的空间，value取值范围是0~255  true是小端，false是大端。
setUint16(offset, value,false) 填充两个字节的空间，就算value是1，他也会占两个空间，第一个空间是1，第二个空间以0填充，value取值范围是0~65535
但是要注意，千万记住这个只能弄独立空间，不能和Uint8Array一样连续填充。假设多个字节，就要循环多次。

上面两个千万记住，传给ArrayBuffer的话，都要通过处理变成数字，字符串也要变成数字


new TextEncoder() 翻译机，把字符串变成数字

他是用来把字符串转换成数字的，例如：
const encoder = new TextEncoder()     // 第1步：造一个"翻译机"
const a='Hi'
const encoded = encoder.encode(a) 
打印出来就是Uint8Array [72, 105]
直接往里面Uint8Array塞就行
```

## 模块音频流协议（发送包）
| 描述 | DATA[] | 说明 |
| ---- | ---- | ---- |
| 帧头标识 | Uint8[4] | 4字节Ascii码包头标识位<br>"code"<br>Value={0x63,0x6F,0x64,0x65} |
| 音频序号 | Uint16 | 小端 |
| 音频名称<br>设备MAC | Uint8[64]<br> | 64字节字符串 暂定GBK编码<br>设备的唯一MAC码，用于区别该音频流属于哪台设备 |
| 话筒ID编号 | Uint16 | 会议主机话筒单元编号：Value = 1-4096（小端）<br>外接独立设备，非会议主机话筒：Value = 0 |
| 音频通道ID | Uint8 | FIFO模式（多通道）：Value = 1-32<br>混音模式（单通道）：value = m，根据不同机型 m = 8、16、32 |
| 音频类型 | Uint8 | Value = 0 ：编码器音频流<br>Value = 1 ：会议主机音频<br>Value = 2 ：声卡音频<br>Value = 3 ：投屏器 |
| 数据字节长度 | Uint16 | 音频数据的字节长度<br>2字节(小端) |
| 音频数据 | uint8[x] | 采样精度16bits，小端<br>40ms每包，每包音频字节长度为1280字节 |

```vue
function stringToUint8Array(str) {
  const encoder = new TextEncoder()
  const encoded = encoder.encode(str) 
   const result = new Uint8Array(str.length)
  // 截取前 fixedLength 字节
  result.set(encoded.subarray(0, str.length))
  return result
}
```

```vue
  /**
   * 开始录音
   * 完整流程：请求麦克风权限 → 选择物理麦克风 → 打开音频流 → 创建音频处理管道 → 降采样 → 分包发送
   */
  let permStream: MediaStream | null = null
   /** 是否正在录音 */
  const isRecording = ref(false)
  
  /** 记录当前正在使用的麦克风 deviceId，用于设备变更时对比判断是否需要切换 */
  let currentMicDeviceId: string | null = null
    // ========== 内部私有变量（非响应式，无需触发视图更新） ==========
  let stream: MediaStream | null = null
   let audioContext: AudioContext | null = null
    let source: MediaStreamAudioSourceNode | null = null
    let processor: ScriptProcessorNode | null = null
   let pcmView: DataView | null = null
  let pcmOffset = 0
 const startRecording = async () => {
    stopRecording()
    // 阶段1：请求麦克风权限（先触发权限弹窗，再关闭临时流）
    permStream = await navigator.mediaDevices.getUserMedia({ audio: true })
    permStream.getTracks().forEach((t) => t.stop())

    // 阶段2：选择真实的默认麦克风
    const realMic = await selectDefaultMic()
    currentMicDeviceId = realMic?.deviceId ?? null

    // 阶段3：用约束条件正式打开麦克风（启用 3A 音频处理）
    const audioConstraints: MediaTrackConstraints = {
      echoCancellation: true,
      noiseSuppression: true,
      autoGainControl: true
    }
    if (realMic) audioConstraints.deviceId = { exact: realMic.deviceId }
    stream = await navigator.mediaDevices.getUserMedia({ audio: audioConstraints })

    // 阶段4：创建 Web Audio API 音频处理管道

    audioContext = new AudioContext()
    source = audioContext.createMediaStreamSource(stream)
    // 获取原始采样率
    const nativeRate = audioContext.sampleRate
    processor = audioContext.createScriptProcessor(4096, 1, 1)
    // 1. 40ms = 0.04 秒
    // 2. 16bit = 2 字节 / 采样点
    // 3. 一包总字节：1280
    // 一包一共有多少个采样点？
    // `1280 ÷ 2 = 640 个采样点`
    // 阶段5：音频数据处理（降采样 + 浮点转PCM + 分包发送）
    processor.onaudioprocess = (event) => {
      //这是从 Web Audio API 的音频处理回调中获取原始音频数据
      const inputData = event.inputBuffer.getChannelData(0)
      // 多少个原始采样点压缩成 1 个目标采样点
      const ratio = nativeRate / SAMPLE_RATE
      //计算降采样后的采样点数量
      const sampleCount = Math.floor(inputData.length / ratio)

      // 降采样 + 浮点转 PCM 16bit
      const samples = new Array<number>(sampleCount)
      for (let i = 0; i < sampleCount; i++) {
        //正常麦克风输出的 Float32 音频样本，理想值就在 -1 ~ 1
        const sample = Math.max(-1, Math.min(1, inputData[Math.floor(i * ratio)]))
        // 浮点转PCM16，正值左移 15 位，负值右移 15 位（正值高位补0，负值高位补1）PCM16（16位有符号整数）的值范围是：-32768 到 3276
        samples[i] = sample < 0 ? sample * 0x8000 : sample * 0x7fff
      }

      // 分包：攒满 PACKET_DATA_SIZE/2 个采样（1280字节=40ms@16kHz）就发一包
      const samplesPerPacket = PACKET_DATA_SIZE / 2 // 640 个采样点
      let srcOffset = 0
      while (srcOffset < samples.length) {
        // 还剩多少采样点没处理
        const remaining = samples.length - srcOffset
        //当前包还差多少采样点填满
        const needed = samplesPerPacket - pcmOffset
        //本次实际拷贝的数量
        const take = Math.min(needed, remaining)

        // 懒初始化 DataView（复用同一块 buffer）
        if (!pcmView) {
          // 创建1280字节的空间
          pcmView = new DataView(new ArrayBuffer(PACKET_DATA_SIZE))
          pcmOffset = 0
        }

        // 显式以小端序写入每个 16bit 采样点（第三个参数 true = little-endian）16bit 采样点（即 2 个字节）到 DataView 中
        for (let i = 0; i < take; i++) {
          //为 PCM 音频数据是 16位有符号整数（Int16），范围 -32768 ~ 32767，所以用 setInt16,setUint16是无符号的，也就是没有负值
          pcmView.setInt16((pcmOffset + i) * 2, samples[srcOffset + i], true)
        }

        srcOffset += take
        pcmOffset += take
        //集满640采样点，发送一包音频数据
        if (pcmOffset >= samplesPerPacket) {
          // 暂停状态下跳过发送，但缓冲区仍要重置，避免恢复时混入旧数据
          if (!isPaused.value) {
            audioStore.sendAudioPacket(new Uint8Array(pcmView.buffer.slice(0)))
          }
          pcmView = null
          pcmOffset = 0
        }
      }
    }

    source.connect(processor)
    processor.connect(audioContext.destination)
    isRecording.value = true
  }
```
