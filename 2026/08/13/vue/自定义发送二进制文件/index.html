描述 DATA[] 说明
帧头标识 Uint8[4] 4字节Ascii码包头标识位
“code”
Value={0x63,0x6F,0x64,0x65}
音频序号 Uint16 小端
音频名称
设备MAC		 Uint8[64]
 64字节字符串 暂定GBK编码
设备的唯一MAC码，用于区别该音频流属于哪台设备
话筒ID编号 Uint16 会议主机话筒单元编号：Value = 1-4096（小端）
外接独立设备，非会议主机话筒：Value = 0
音频通道ID Uint8 FIFO模式（多通道）：Value = 1-32
混音模式（单通道）：value = m，根据不同机型 m = 8、16、32
音频类型 Uint8 Value = 0 ：编码器音频流
Value = 1 ：会议主机音频
Value = 2 ：声卡音频
Value = 3 ：投屏器
数据字节长度 Uint16 音频数据的字节长度
2字节(小端)
音频数据 uint8[x] 采样精度16bits，小端
40ms每包，每包音频字节长度为1280字节
